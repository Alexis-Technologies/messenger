# Getting Started

::: warning Work in progress
@alexify/messenger is being designed. The package can be installed, but `createMessenger` is a
placeholder that throws `createMessenger is not implemented yet`.
:::

## Installation

```bash
pnpm add @alexify/messenger
# or
npm install @alexify/messenger
```

Node.js 22 or newer, Bun or Deno (`npm:@alexify/messenger`). The package has no runtime
dependencies.

## Importing

```js
const { createMessenger } = require('@alexify/messenger');
```

```js
import { createMessenger } from '@alexify/messenger';
```

See [Why @alexify/messenger?](/guide/why) for what the library is built to do, and the
[API](/api/exports) for the current exports.
